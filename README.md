# 冰雪故事书 · 魔法词书 / Frozen Storybook & the Magic Word Book

一款面向 5–9 岁儿童的**中英对照闯关式网页剧情游戏**。以附件《Frozen Storybook Collection》18 篇故事指南为蓝本，**完整保留全书 18 篇的篇目顺序、作者、故事主线与关键情节点**，并把每一篇改编成一个可玩的章节。

---

## 二、如何运行

1. 直接**双击 `index.html`**（`file://` 协议即可，无需服务器、无需构建、无需联网）。
2. 或起一个本地静态服务（可选）：`cd /workspace && python3 -m http.server 8080`，浏览器打开 `http://localhost:8080`。
3. 首次进入填一个名字（会写进词书扉页与结局台词），点「开始闯关」。

> **兼容性**：浏览器有彩色 emoji 字体时显示彩色图标；检测到缺失时**自动降级为彩色汉字徽章**（识字卡风格），任何环境都不会出现方框乱码。英文发音使用浏览器内置语音合成，不支持时静默降级，不影响游戏。进度保存在本机 `localStorage`，不上传。

## 三、游戏怎么玩（每章固定节奏，18 章一致）

| 步 | 环节 | 学什么 | 叙事作用 |
|---|---|---|---|
| 1 | 章封面 | 篇名 / 作者 / 地点 / 本篇主线 | 建立期待 |
| 2 | **起**（Beginning） | 3–4 句双语对白 | 交代起因 |
| 3 | ① 认单词 Word Gate | 6 个主题词，看图选词 + 发音 | 词汇输入 |
| 4 | **承**（Middle） | 3–4 句双语对白 | 推进冲突 |
| 5 | ② 排情节 Story Order | 把该篇 3 张剧情卡按起因→经过→结果排序 | **检验主线掌握** |
| 6 | **转**（End） | 3–4 句双语对白 | 收束结果 |
| 7 | ③ 拼句子 Build a Sentence | 词块拼出本章魔法句 | 句型输出 |
| 8 | ④ 你会怎么做？ Your Choice | 3 个价值不同的选择 | 分支与后果 |
| 9 | 魔法句时刻 Magic Sentence | 大声说出来 → 画面变化 → 点亮词书一页 | 故事与玩法合一 |
| 10 | 章末回顾 | 主线一句话 + 6 词 + 魔法句 | 复述与巩固 |

**无计时、无失败、无扣分**。答错只给温和提示并可无限重试；三个分支没有对错，只改变角色的回应、即时画面与获得的贴纸。第 1 章通关后解锁第 2 章；家长角的「课堂模式」可一次解锁全部 18 章供课堂演示。

右上角可切换 **中英对照 / 仅 English / 仅中文**；「仅英文」「仅中文」模式下有「🤫 显示…」按钮，适合先猜后核对。

| 2 | 基调 | 轻快、温暖、幽默；沿用「心意 > 排场」「安抚 > 对抗」；**零悲剧、零反派、无人受伤或离世** | ☐ |

## 六、技术与数据

- **单文件**：HTML + 内联 CSS + 内联 JS + 内嵌 JSON 数据，`file://` 下不发起任何网络请求。
- **存档**：`localStorage['frozen_storybook_v1']`，含 `name / mode / sound / autoRead / classroom / completed / stickers / eggs / flags / stats / ended`。家长角可一键清空。
- **图标降级**：canvas 检测彩色 emoji 字形，缺失时用 MutationObserver 把图标替换为按字符哈希着色的汉字徽章。
- **语音**：`SpeechSynthesisUtterance`，英文 `rate=0.78`、中文 `0.9`；不支持时按钮仍可点，不报错。
- **键盘**：`Enter` / `Space` 继续，`1/2/3` 选项，`Esc` 回目录；按钮最小高度 42–56px；`prefers-reduced-motion` 下关闭动画。
- **家长角**：按章统计单词/排序/拼句尝试次数、朗读次数、所选分支、彩蛋收集，只用于复习参考、不给孩子看分数。
- **校验**：18 篇篇目与作者顺序、每章 3 幕（起/承/转）、每章 6 词 / 3 张情节卡 / 3 个价值不同的分支、魔法句 token 拼接一致性、四组覆盖 1–18、分支收敛无死路 —— **0 错误 0 警告**；Chromium 无头全链路 **47 项检查通过、0 个 JS 错误**。
